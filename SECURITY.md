# Security policy

> ⚠️ This is an unofficial modification of Whisk. It is not maintained by the upstream author.

Security reports for this fork can be opened as a repository issue. For upstream Whisk vulnerabilities, follow the upstream security policy at <https://github.com/nathan-poncet/whisk/security>.

Because this build handles clipboard content, treat it as sensitive software: review the source, build from source when possible, and do not install it alongside the official Whisk unless you understand the shared Bundle ID risk.
