# Xiaomi system sounds

These three short sounds are taken from the public repository
`DevOtag-Open-Source/miui12-soundpack`:

- `WaterDropNotificationDay1.caf` from `system/media/audio/ui/WaterDropNotificationDay1.ogg`
- `BirdCicadaNotificationDay1.caf` from `system/media/audio/ui/BirdCicadaNotificationDay1.ogg`
- `WindChime.caf` from `system/media/audio/notifications/WindChime.ogg`

The source repository declares the work under GPL-3.0-or-later. Whisk is
distributed under GPL-3.0-or-later, and these files are converted from OGG
to CAF without changing the audible content.

Source repository:
https://github.com/DevOtag-Open-Source/miui12-soundpack
